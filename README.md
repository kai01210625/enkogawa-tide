# 猿猴川 潮汐ログ (Enkogawa Tide Logger)

猿猴川でのチヌ釣り記録 × 気象庁潮位データの可視化 × 相関分析用Excel書出しPWA。**屋外スマホ使用に最適化済み**。

## 釣り場での使用

このアプリは現場での片手スマホ操作を前提に設計されています。

### 釣り場最適化機能
- **巨大HITボタン**: 高さ110px、グローブや濡れた指でも押せるサイズ
- **誤タップ防止**: 1秒以内の連打は自動で無視。釣り中の暴発を防ぎます
- **強めのバイブ**: HIT記録時にパターンバイブで確実なフィードバック (60-30-80ms)
- **屋外モード(☀ボタン)**: 純黒背景+高コントラスト+大型フォントに切替。直射日光下でも視認性確保
- **スリープ防止(🔓ボタン)**: 画面ロックされず釣りに集中できる (Wake Lock API)
- **進行中表示**: 上部にルアー色 + 経過時間 (例「赤 38分」) を常時表示
- **HITボタンの状態表示**: 進行中セッションがあれば「赤 投入中」とサブ表示
- **大型タップターゲット**: 全ボタン最低44px、主要ボタンは48〜64px
- **ボトムシートUI**: ルアー選択は画面下部から大きく出現、片手で届く位置
- **ホーム画面追加対応**: PWAインストール後はアプリ同等の起動感

### 現場での典型的なフロー
1. アプリを開く → 「☀」「🔒」で屋外モードとスリープ防止をON
2. 「▶ 投入開始」 → 使うルアー色を選択
3. 釣り開始 → ヒットしたら巨大な「＋HIT」ボタンを叩く (色は自動継承)
4. ルアー変更時 → 「変更」ボタン → 新しい色選択 (前セッション自動終了)
5. 撤収時 → 「終了」ボタン

## 機能

- **ワンタップHIT記録**: 釣行中に大きな赤いボタンをタップ → 現在時刻で即記録
- **投入セッション管理**: 「投入開始」「ルアー変更」「終了」ボタンで連続区間×ルアー1個を自動記録。手動入力も可能
- **真のヒット率算出**: セッション時間を分母にした「時間あたりHIT」を色別・潮汐位相別・潮位帯別に算出
- **詳細入力**: ルアー色・サイズ・天候・メモを追加可能
- **潮位カーブ + HIT点 + セッション帯の重ね描き**: 選択日の天文潮位とヒットタイミング、各セッションの投入時間帯を色帯として可視化
- **満潮/干潮時刻表示**: 当日の高低潮の時刻と潮位を上部に表示
- **アプリ内集計**: ルアー色別・潮位帯別のヒット数
- **Excel書出し**: 相関分析用に11シート構成のxlsxを生成(後述)
- **CSV/JSONエクスポート**: 他ツール連携用
- **オフライン動作**: Service Workerでキャッシュ。電波が弱い釣り場でも使用可能

## セッション(投入)記録の使い方

### 自動モード(おすすめ・釣行中)
1. アプリ上部の「**＋投入開始**」をタップ → 色を選択 → セッション開始(進行中表示)
2. ルアーをチェンジするとき: 「**ルアー変更**」ボタン → 新しい色を選択 → 前のセッションは自動終了、新セッション開始
3. 釣り終わり: 「**終了**」ボタン

進行中セッションがある間にHITボタンを押すと、ヒット記録に**現在のルアー色が自動継承**されます。

### 手動モード(後から振り返り入力)
「投入」タブ → 開始/終了時刻+色を入力して「セッションを追加」。釣行後にまとめて入力する場合に。

両モードを混在させても問題ありません。同じ投入タブで一覧表示・削除できます。

## Excel書出しの中身

「データ」タブ → 「Excel書出し」で `enkogawa_YYYY-MM-DD.xlsx` が生成され、最大11シートが含まれます。**Excelで開いた瞬間に COUNTIFS/SUMIFS/IFERROR で自動再計算される動的シート**なので、Hits_RawやSessions_Rawの行を編集すれば集計も即更新されます。

### 生データ系
| シート | 内容 |
|---|---|
| `Hits_Raw` | 全ヒット記録 + 派生列(潮位・位相・直近満干潮からの分など) |
| `Sessions_Raw` | 全投入セッション + 派生列(継続分・中央時刻潮位/位相・HIT数・HIT/h) |
| `Tide_Hourly` | 日付×時間(h00〜h23)の毎時潮位マトリクス |
| `Tide_HighLow` | 日次の満干潮時刻・潮位 + 干満差(range_cm) |

### ヒット**回数**集計 (分母なし。サンプルサイズの把握用)
| シート | 内容 |
|---|---|
| `Crosstab_Color_Tide` | 色 × 潮位帯のヒット回数クロス集計 |
| `Crosstab_Color_Phase` | 色 × 潮汐位相のヒット回数クロス集計 |

### ヒット**率**集計 (分母つき。**相関分析の主役**)
| シート | 内容 | 計算 |
|---|---|---|
| `Hit_Rate_Summary` | 色別の セッション数・投入分・HIT数・HIT/h・HIT/セッション | SUMIF / COUNTIF |
| `Hit_Rate_Color_Phase` | 色×位相 のセッション数・投入分・HIT/h | SUMIFS / COUNTIFS |
| `Hit_Rate_Color_Tide` | 色×潮位帯 のセッション数・投入分・HIT/h | SUMIFS / COUNTIFS |

### その他
| シート | 内容 |
|---|---|
| `Summary` | 概要統計 |
| `README` | 列定義・推奨される分析フロー |

## 推奨される相関分析の流れ

### Step 1. 記述統計 (Excel上だけで完結)
- `Hit_Rate_Summary` を見て、色別のHIT/hを比較
- `Hit_Rate_Color_Phase` で「赤×下げ潮」のような交互作用を目視

### Step 2. ポアソン回帰 (R) — ヒット率の検定として最も適切
`Sessions_Raw` を直接モデル化。各セッションのHIT数を応答変数、投入分をオフセットにすることで「単位時間あたりHIT率」を比較できます。
```r
library(readxl)
df <- read_excel("enkogawa_2026-XX-XX.xlsx", sheet = "Sessions_Raw")

# 主効果モデル: 色のみ
m1 <- glm(hits_in_session ~ color, offset = log(duration_min/60),
          family = poisson, data = df)
summary(m1)

# 交互作用モデル: 色×位相
m2 <- glm(hits_in_session ~ color * mid_phase, offset = log(duration_min/60),
          family = poisson, data = df)
summary(m2)
anova(m1, m2, test = "Chisq")  # 交互作用の有意性

# 過分散があれば負の二項回帰
library(MASS)
m3 <- glm.nb(hits_in_session ~ color * mid_phase + offset(log(duration_min/60)), data = df)
```

### Step 3. Python版 (statsmodels)
```python
import pandas as pd, numpy as np
import statsmodels.api as sm
import statsmodels.formula.api as smf

df = pd.read_excel("enkogawa_2026-XX-XX.xlsx", sheet_name="Sessions_Raw")
df = df[df["duration_min"] > 0]  # ゼロ除算回避

model = smf.glm(
    "hits_in_session ~ C(color) * C(mid_phase)",
    data = df,
    family = sm.families.Poisson(),
    offset = np.log(df["duration_min"] / 60),
).fit()
print(model.summary())
```

### Step 4. ヒット回数だけのカイ二乗(参考扱い)
`Crosstab_Color_Tide` / `Crosstab_Color_Phase` をRやPythonに渡してカイ二乗。
ただし**投入時間を考慮しない**ため、「赤を多く投げたから赤が多いだけ」というバイアスが排除できません。Step 2-3 を主軸にすべきです。

## カイ二乗との違い (重要)

| | カイ二乗 (Crosstab_*) | ポアソン回帰 (Sessions_Raw) |
|---|---|---|
| 分母 | なし(ヒット回数のみ) | セッション時間(分) |
| 解釈 | 「投入されたうち、どの組合せでヒットが偏ったか」 | 「単位時間あたりのヒット率がどう違うか」 |
| バイアス | 投入比率の影響を強く受ける | 投入時間で補正される |
| 推奨度 | 補助的 | **本命** |

過去の600+データポイントを使った「赤ルアー優位 (p<0.01)」研究も、もしルアー使用時間が記録されていれば、本シートの形式に移行することで真のヒット率比較に発展できます。

## 気象庁潮位データの取得方法

ブラウザのCORSポリシーで気象庁サーバーから直接fetchすると失敗することが多いため、2系統用意:

### A. 自動取得 (CORSプロキシ経由)
「自動取得（試行）」ボタンで公開CORSプロキシ経由でトライ。動けば1年分のデータが一発で入ります。

### B. テキスト貼付け (確実)
1. [気象庁・広島Q8の潮位表](https://www.data.jma.go.jp/kaiyou/db/tide/suisan/suisan.php?stn=Q8) を開く
2. 「テキストデータ版」をダウンロード(またはコピー)
3. 「テキスト貼付け」エリアにペースト → 「取込み」
4. 気象庁の固定幅フォーマット(1日=1行、24時間×3バイト+YYMMDD+地点記号+満干潮)を正確にパース
